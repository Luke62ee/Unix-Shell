# 🐚 Unix Shell Project

A custom Unix Shell implemented in C, designed to execute user commands in separate processes, support input/output redirection, and facilitate inter-process communication using pipes.

## 🚀 Features
- 🛠️ **Command Execution** – Run UNIX commands in a separate child process
- 📜 **Command History** – Execute the last command using `!!`
- 🔄 **Redirection Support** – Use `>` and `<` for output and input redirection
- 🔗 **Pipelining** – Support for `|` to connect processes
- 🏃 **Background Execution** – Run processes concurrently using `&`
- 🎨 **ASCII Easter Egg** – Enter `ascii` for a fun surprise! 🎉
